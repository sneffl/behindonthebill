# behindonthebill.com

The front door for Behind on the Bill. This page keeps behindonthebill.com in the
address bar and loads the app (hosted on shinyapps.io) inside it, with a loading
screen while the free server wakes up. og-image.png is the preview card that shows
up when someone shares the link in a text or on LinkedIn.

App source: https://github.com/sneffl/utility-risk-model
